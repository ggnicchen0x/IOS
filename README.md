# iOS Tweak Cloud Builder

Upload all files in this folder to a GitHub repository.

## Steps:
1. Create a new GitHub repo (e.g. `ffmax-tweak-builder`).
2. Upload the contents of this folder (`github_tweak_builder/`).
3. Click the **Actions** tab on GitHub -> Click **Build iOS Tweak (.deb)** -> Click **Run workflow**.
4. When finished, download the **FFMAXLicense-deb** artifact.
5. Install the `.deb` on your iPhone using Filza!
